# La Belle et la Bête — outil de révision 6e

Outil interactif de révision pour l’étude du conte **La Belle et la Bête** de Jeanne-Marie Leprince de Beaumont.

## État du projet

- `index.html` : page web interactive (résumé, frise chronologique, exercices, lecture du texte et lecture vocale).
- `assets/jeanne-marie-leprince-de-beaumont.jpg` : portrait local utilisé par la page, afin d’éviter une dépendance à une URL Wikimedia devenue indisponible.
- Le texte et les contenus pédagogiques seront comparés au PDF de référence fourni par l’autrice du projet avant la prochaine mise à jour.

## Correction actuelle

Le portrait de Jeanne-Marie Leprince de Beaumont a été intégré localement dans le dépôt. Les deux références à l’ancienne URL Wikimedia ont été remplacées par le fichier `assets/jeanne-marie-leprince-de-beaumont.jpg`.

Source du portrait : [Wikimedia Commons — Jeanne-Marie Leprince de Beaumont](https://commons.wikimedia.org/wiki/File:Jeanne-Marie_Leprince_de_Beaumont.jpg).

## Utilisation

Ouvrir `index.html` dans un navigateur, ou publier le dépôt avec GitHub Pages.

Le code est disponible dans le dépôt GitHub : https://github.com/cecilesauder/La_Belle_et_la_Bete. L’activation automatique de GitHub Pages n’a pas été autorisée par les droits de l’intégration ; elle pourra être activée dans **Settings → Pages**, avec `main` et le dossier `/ (root)`.

# La Belle et la Bête — outil de révision 6e

Outil interactif de révision pour l’étude du conte **La Belle et la Bête** de Jeanne-Marie Leprince de Beaumont.

## État du projet

- `index.html` : page web interactive (résumé, frise chronologique, exercices, lecture du texte et lecture vocale).
- `assets/jeanne-marie-leprince-de-beaumont.jpg` : portrait local utilisé par la page, afin d’éviter une dépendance à une URL Wikimedia devenue indisponible.
- Le texte de lecture est une adaptation abrégée en cours de comparaison avec le PDF fourni par l’enseignant (Barba, 1806).

## Utilisation

Ouvrir `index.html` dans un navigateur, ou publier le dépôt avec GitHub Pages.

Le code est disponible dans le dépôt GitHub : https://github.com/cecilesauder/La_Belle_et_la_Bete. L’activation automatique de GitHub Pages n’a pas été autorisée par les droits de l’intégration ; elle pourra être activée dans **Settings → Pages**, avec `main` et le dossier `/ (root)`.
## Comparaison avec le PDF de l’enseignant

Les deux documents ne sont pas la même édition :

- le PDF indique **Contes moraux pour l’instruction de la jeunesse, Barba, 1806** ;
- l’ancien HTML indiquait **Wikisource 1883**, mais son lecteur ne contenait pas le texte intégral : il s’arrêtait après la transformation de la Bête en prince et ne comptait que 77 phrases de lecture ;
- le PDF contient le dénouement complet : Belle retrouve son père et sa famille, une grande fée la récompense, puis les deux sœurs sont changées en statues tout en conservant leur raison jusqu’à la reconnaissance de leurs fautes ;
- l’ancien résumé HTML simplifiait aussi plusieurs scènes et présentait les deux sœurs comme responsables du retard, sans raconter leur punition finale.

La page indique désormais clairement qu’il s’agit d’une **version pédagogique adaptée**. Le lecteur inclut le dénouement manquant sur les statues, mais une harmonisation phrase par phrase avec tout le PDF pourra être faite dans une prochaine étape si nécessaire.

## Exercices ajoutés

Trois formats supplémentaires sont disponibles dans l’onglet **Révisions** :

- six affirmations **Vrai / Faux** avec correction immédiate ;
- une activité pour **remettre les cinq événements dans l’ordre** avec des flèches ;
- une activité **Qui parle ?** pour identifier les personnages à partir de leurs répliques.
